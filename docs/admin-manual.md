## 二、用户管理

### 2.1 查看用户列表

1. 点击左侧菜单【用户管理】
2. 查看【用户】标签页
3. 用户列表显示：
   - 用户名
   - 角色
   - 所属堂区
   - 创建时间
   - 操作按钮

### 2.2 创建用户

1. 点击【新建用户】按钮
2. 在对话框中填写：
   - **用户名**：登录账号（必填，唯一）
   - **密码**：初始密码（必填）
   - **角色**：选择用户角色（必填）
   - **所属堂区**：录入员必须选择
3. 点击【确定】创建

### 2.3 编辑用户

1. 找到要编辑的用户
2. 点击【编辑】按钮
3. 可修改：
   - 用户角色
   - 所属堂区
   - 可访问堂区（观察员）
4. 点击【确定】保存

### 2.4 重置密码

1. 找到需要重置密码的用户
2. 点击【重置密码】按钮
3. 输入新密码（两次确认）
4. 点击【确定】完成重置

### 2.5 删除用户

1. 找到要删除的用户
2. 点击【删除】按钮
3. 确认删除操作

> ⚠️ 注意：admin 账号不可删除。

## 三、角色权限管理

### 3.1 系统角色

系统预置三种角色：

| 角色名称 | 权限说明 |
|---------|---------|
| 超级管理员 | 拥有所有权限，可管理全部堂区数据 |
| 录入员 | 可管理所属堂区的家庭和成员信息 |
| 观察员 | 只读访问授权堂区的数据 |

### 3.2 权限列表

系统定义以下权限：

| 权限代码 | 权限名称 | 说明 |
|---------|---------|------|
| user_manage | 用户管理 | 创建、编辑、删除用户 |
| role_manage | 角色管理 | 管理角色权限 |
| village_manage | 堂区管理 | 管理堂区信息 |
| household_manage | 家庭管理 | 完整的家庭增删改查 |
| household_view | 家庭查看 | 只读查看家庭信息 |
| member_manage | 成员管理 | 完整的成员增删改查 |
| member_view | 成员查看 | 只读查看成员信息 |

### 3.3 角色权限分配

1. 进入【用户管理】
2. 切换到【角色】标签页
3. 选择要查看的角色
4. 点击【详情】查看权限配置

### 3.4 数据范围控制

不同角色的数据访问范围：

- **超级管理员**：可访问所有堂区数据
- **录入员**：仅可访问 `village_id` 指定的堂区数据
- **观察员**：可访问 `accessible_villages` 中指定的多个堂区数据

## 五、数据备份与恢复

### 5.1 数据库备份

#### 5.1.1 通过系统下载

1. 进入【系统设置】页面
2. 点击【下载数据库备份】按钮
3. 选择保存位置

#### 5.1.2 手动备份（PostgreSQL）

```bash
pg_dump -U household_user household_system > backup_$(date +%Y%m%d).sql
```

### 5.2 数据库恢复

#### 5.2.1 手动恢复

```bash
# 恢复前先备份当前数据库
pg_dump -U household_user household_system > pre_restore_backup.sql

# 恢复数据库
psql -U household_user household_system < backup.sql
```

### 5.3 定期备份建议

建议配置自动备份任务：

```bash
# 编辑 crontab
crontab -e

# 添加每天凌晨2点自动备份
0 2 * * * pg_dump -U household_user household_system | gzip > /backup/household_$(date +\%Y\%m\%d).sql.gz
```

## 六、系统维护

### 6.1 服务管理

```bash
# 查看服务状态
sudo systemctl status household-backend

# 启动服务
sudo systemctl start household-backend

# 停止服务
sudo systemctl stop household-backend

# 重启服务
sudo systemctl restart household-backend
```

### 6.2 日志查看

```bash
# 查看后端日志
tail -f /var/log/household/backend.log

# 查看 Nginx 日志
tail -f /var/log/nginx/access.log
tail -f /var/log/nginx/error.log
```

### 6.3 健康检查

```bash
# 检查后端服务
curl http://localhost:8000/api/v1/health

# 检查数据库连接
curl http://localhost:8000/api/v1/health/db
```

### 6.4 常见问题处理

#### 问题1：服务无法启动

检查项：
1. 数据库连接是否正常
2. 配置文件是否正确
3. 端口是否被占用
4. 日志中的错误信息

```bash
# 检查端口占用
netstat -tlnp | grep 8000

# 检查数据库连接
psql -U household_user -d household_system -c "SELECT 1;"
```

#### 问题2：用户无法登录

检查项：
1. 用户账号是否存在
2. 用户是否被禁用
3. 密码是否正确
4. 检查后端日志

#### 问题3：数据访问异常

检查项：
1. 用户权限配置
2. 用户堂区分配
3. 数据库连接状态

### 6.5 性能优化建议

1. **数据库优化**
   - 定期执行 VACUUM
   - 创建必要的索引
   - 监控慢查询

2. **应用优化**
   - 监控内存使用
   - 调整 worker 数量
   - 启用响应压缩

3. **存储优化**
   - 定期清理上传目录
   - 监控磁盘空间
   - 备份旧数据

## 附录：安全建议

### 账号安全

1. 立即修改默认管理员密码
2. 使用强密码（8位以上，包含大小写字母、数字、特殊字符）
3. 定期更换密码
4. 及时停用离职人员账号

### 系统安全

1. 启用 HTTPS
2. 配置防火墙规则
3. 定期更新系统和依赖
4. 定期审计用户权限

### 数据安全

1. 定期备份数据库
2. 异地保存备份
3. 测试恢复流程
4. 记录操作日志
