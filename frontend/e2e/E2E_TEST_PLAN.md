# 前端 E2E 测试计划

## 1. 测试目标
使用 Playwright 对 Web 系统进行端到端测试，覆盖所有用户功能，确保迁移后的 Web 系统功能完整、权限控制正确。

## 2. 测试环境
- 框架: Playwright
- 测试浏览器: Chromium
- 后端: FastAPI (localhost:8000)
- 前端: Vite Dev Server (localhost:5173)

## 5. 测试执行策略

### 5.1 测试顺序
1. 先执行登录模块测试（其他测试依赖登录）
2. 按模块顺序执行：仪表盘 → 堂区 → 家庭 → 成员 → 搜索 → 打印 → 设置 → 用户/角色 → 个人中心
3. 最后执行权限控制测试

### 5.2 测试数据准备
- 使用后端初始化的默认数据
- 测试创建的数据在测试后清理
- 不依赖特定数据的测试使用动态创建

### 5.3 失败处理
- 测试失败时记录截图和日志
- 通知 Coder agent 修复
- 修复后重新执行失败的测试

## 6. 验收标准
- 所有测试用例 100% 执行
- 测试通过率 >= 95%
- 无阻断级缺陷
- 核心功能（登录、堂区、家庭、成员、权限）测试通过率 100%
